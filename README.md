# A1 Brothers Hub 🍔

A clean and modern food menu web application built using **HTML5** and **CSS3**. This project features a responsive menu card grid, a structured pricing table for special offers, and an interactive contact section.

## 🚀 Live Demo
*https://errortitus.github.io/a1-brothers-hub/*

---

## 🛠️ Built With
* **HTML5** - Semantic layout structure, tables, and forms.
* **CSS3** - Flexbox, hover transitions, custom styling, and responsive layout designs.

---

## ✨ Features
* **Navigation Header:** Quick links to Home, Menu, Offers, and Contact sections.
* **Special Dishes Grid:** Styled food cards with high-quality images, descriptions, prices, and "Order Now" buttons with smooth hover animations.
* **Special Offers Table:** Clean tabular layout displaying food items and promotional pricing.
* **Contact Us Form:** Fully structured form with name, email, and message inputs.
